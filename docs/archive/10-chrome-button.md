# To do 10: Chrome button (large): "Edge button: send the page you're on to the app"

First written for Edge; the user mostly uses Chrome, so it became a Chrome button (2026-11-13, docs/decisions.md).

- **Goal:** on a video page in Chrome, one click sends the link to the app. Example: on a YouTube video, click the button; the app comes to the front with the link filled in.
- **Read first:** docs/research/browser-button.md (researched 2026-11-13); `start()` and `main()` in app.py.
- **Approach:** an unpacked Chrome extension (toolbar button) plus native messaging: a host manifest and Chrome's registry key `HKCU\Software\Google\Chrome\NativeMessagingHosts\video_downloader`, which start a small helper; the helper hands the link to the open window through a named pipe, or opens a window with the link. Decided 2026-11-13: docs/decisions.md.
- **Answered (2026-11-13, the user went with the suggestions):** (a) only fill in the link and bring the window to the front, replacing a link already in the box, with "Link received: choose MP4 or MP3, then Download." in the status line; (b) after the queue: yes, To do 9 is built; setup with `python -m video_downloader.browser install` / `uninstall`; Chrome only.
- **Answered for step B (2026-11-14, the user went with the suggestions):** (a) a page that isn't a web page (New Tab, `chrome://`, a file from disk) is not sent: "!" on the button, tooltip "Only web pages can be sent."; (b) nothing in Chrome when it works (the app coming to the front is the sign); "!" when it fails, its tooltip says why, gone at the next click that works; (c) icon: a white down arrow on a blue rounded square, drawn once with Pillow, only the PNGs committed; (d) name "Video Downloader", tooltip "Send this page to Video Downloader". Also (Claude, in the plan): the helper is its own module `host.py`, not part of `browser.py`, because importing `downloader` (yt-dlp) costs 0.18-0.37 s per click (measured 2026-11-14).
- **Test:** Claude: tests for the link hand-over and the helper without a browser. User: load the extension, click it on a YouTube page.
