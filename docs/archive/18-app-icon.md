# To do 18: The app uses the Chrome button's icon (small): "Shouldn we use the icon for the chrome extension as the icon for the app itself?"

- **Problem:** the app sets no icon (app.py has no `iconphoto`), so its title bar shows Tk's feather and its taskbar button shows Python's icon. Since To do 16, a download from Chrome opens the app minimized, so the taskbar button is the only sign it's running, and it looks like any Python program.
- **Goal:** the window's title bar, its taskbar button and Alt+Tab show the Chrome button's icon (a white down arrow over a bar on a blue rounded square). Example: with the app closed, Download in the Chrome popup: the taskbar gets the same blue arrow as Chrome's toolbar.
- **Read first:** app.py `App.__init__` (near `root.title(TITLE)`) and `start()` (the DPI call before `tk.Tk()`); browser.py `EXTENSION_FOLDER`; extension/icons/ (16, 32, 48 and 128 px PNGs); docs/research/browser-button.md "Icons" (how they were drawn); tests/gui/drive.py `open_window()`.
- **Approach (suggested; the build session checks it):** `root.iconphoto(True, ...)` with a `tk.PhotoImage` per PNG (Tk 8.6 reads PNG; the images must stay referenced), read from extension/icons so there is one copy. The taskbar: Windows often files a `pythonw` window under Python and shows Python's icon there whatever the window's icon (general knowledge, not tested); the usual fix is `SetCurrentProcessExplicitAppUserModelID` (shell32) with an ID of the app's own, called in `start()` before the window opens. Check on this PC, with and without it.
- **Ask the user:** (a) the icon in the title bar and Alt+Tab too, not only the taskbar? Suggested: yes (the same call does all). (b) An `.ico` file for the installer now? Suggested: no, To do 11 makes it when it needs one.
- **Test:** Claude: an app test that the window gets the icon's images (all four sizes load); the screenshots show the title bar, so its icon can be seen there. User: the title bar, the taskbar button and Alt+Tab show the blue arrow, also when the window was opened minimized from the Chrome popup.
